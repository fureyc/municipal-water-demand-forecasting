# Colorado Municipal Water-Demand Forecasting

This project develops a reproducible Python workflow for acquiring,
validating, integrating, and modeling municipal water-demand and weather data.

## Project status

Active development. The current phase focuses on data acquisition,
validation, and preprocessing.

## Initial data sources

- Fort Collins municipal water-demand data
- NOAA weather and climate observations

## Planned workflow

1. Download municipal water-demand data.
2. Download relevant NOAA weather observations.
3. Validate the raw inputs.
4. Construct a daily modeling dataset.
5. Develop and evaluate water-demand forecasting models.
